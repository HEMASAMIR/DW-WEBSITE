# تشغيل موقع Deutsche Welt على السيرفر

الموقع Next.js ولازم يشتغل **كسيرفر Node** (مش ملفات static)، لأنه بيكلّم الباك إند
`https://py.deutschewelt.academy` من خلال سيرفر الموقع نفسه.

## 1) المتطلبات
- Node.js 20 أو أحدث

## 2) الإعدادات (Environment Variables)
اعمل ملف `.env.local` جوه فولدر `frontend` (أو حطها في إعدادات الاستضافة):

```env
# حساب طالب مخصوص للموقع — من غير أي اشتراكات، ومش أدمن.
# بيخلّي الزوار (اللي مش مسجلين) يشوفوا المستويات والكتب بأسعارها الحقيقية.
CATALOG_ACCOUNT_EMAIL=catalog@example.com
CATALOG_ACCOUNT_PASSWORD=********

# رقم واتساب الاشتراكات والطلبات (بالصيغة الدولية من غير +)
NEXT_PUBLIC_WHATSAPP_NUMBER=2010552287454

# اختياري: زرار الدخول بجوجل
# NEXT_PUBLIC_GOOGLE_CLIENT_ID=
```

> ماتحطش `NEXT_PUBLIC_API_URL` — الموقع بيوصل للباك إند لوحده.
> الباك إند الافتراضي هو `https://py.deutschewelt.academy`؛ لو اتغيّر حط `BACKEND_URL=...`.

## 3) التشغيل
```bash
cd frontend
npm install
npm run build
npm run start        # بيشتغل على بورت 3000 — أو: npm run start -- -p 80
```

على Vercel: اعمل Import للريبو، واختار `frontend` كـ Root Directory، وحط الإعدادات اللي فوق
في Environment Variables.

## 4) اتأكد إنه شغال
- افتح الموقع من غير تسجيل دخول: المستويات والكتب لازم تظهر بأسعارها.
- سجّل دخول بحساب طالب: المستويات المفعّلة ليه تفتح بالفيديوهات.
- سجّل دخول بحساب أدمن: زرار لوحة التحكم يظهر في الهيدر.

## الفروع وإعلان الموقع
الفروع وشريط الإعلان بيتعدّلوا من لوحة التحكم، والموقع نفسه بيحفظهم في ملفات JSON
جوه فولدر `frontend/data/` (أو المسار اللي في `SITE_DATA_DIR`).
- لازم الفولدر ده يكون **قابل للكتابة** ومايتمسحش مع كل رفع جديد، فخلّي `SITE_DATA_DIR` يشاور على مكان ثابت على السيرفر.
- على Vercel التعديلات **مش هتتحفظ** لأن الـ disk بتاعه read-only. استخدم VPS أو أي سيرفر Node عادي.

## ملاحظات
- كل البيانات (الأسماء، الأسعار، المفعّل وغير المفعّل) جاية من الباك إند — مفيش أي بيانات
  مكتوبة جوه الكود.
- ملف `src/constants/temporaryAdmins.js` مؤقت: امسحه أول ما الباك إند يرجّع `groups`
  في رد تسجيل الدخول.
